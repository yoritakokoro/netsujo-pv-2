# 熱情エナモラル MV v6 企划书（从头重做）

## 0. 这次要解决的问题

v5 被评价为「像 PPT 联播」。原因不在素材，而在剪辑和运动：

| 症状 | 原因 | v6 的做法 |
|---|---|---|
| 一页一页地换 | 画面静止，元素在原地淡入淡出 | 每个镜头从第一帧起就在动，镜头路径连续，跨剪辑保持速度 |
| 转场软、没有冲击 | 几乎都是淡入淡出 | 转场卡在拍子上：闪白、过曝溶解、推穿、甩镜、负片、主题擦除（扇子、裙摆、拱门） |
| 字幕像贴上去的 | 字在固定位置淡入 | 字跟着唱一个个「爆」出来：大而白热，再缩回原位并冷却；整行慢慢漂移 |
| 字幕挡脸 | 没有脸部避让 | 每个镜头登记脸部范围，歌词排在脸旁边；程序会检查，冲突时自动换到另一侧 |
| 像幻灯片的版式 | 物件摆在纯色背景上 | 满画幅：插画特写、材质铺满、前景（花瓣、蕾丝、光斑）从镜头前掠过 |

参考：两段学マス Lyric Video（冠菊 / キミとセミブルー）、四段录屏，以及 he-drowns-mv-v2（强度曲线、按打击乐驱动画面、镜头是歌曲时间的纯函数、卡点切镜）。只借鉴思路，画面语言仍然是弗拉明戈。

运动强度跟随这条曲线：

- 安静段：慢推、慢移，拍点只做轻微的光呼吸。
- 中等段：每拍轻微缩放脉冲，小节头一次曝光闪。
- 高潮段：每拍缩放脉冲 + 径向模糊，强拍闪白，元素按拍变色、旋转。

## 3. 运动与剪辑规则

1. **永不静止**：每个镜头有完整的镜头路径（推、拉、横移、升降），外加极轻的手持漂移。整幅画面一起运动：人物和背景不再相对滑动，只有前景粒子和文字层有视差。
2. **卡点**：剪辑落在强拍或乐句起点；关键字落在被唱出的那一刻（例如「太陽」出现时太阳升起）。
3. **转场库**（全部按拍）：
   - **闪白**：一帧白，下一镜从过曝中显出。用于段落爆点。
   - **过曝溶解**：前一镜曝光升高、发糊，后一镜从光里显出。用于抒情。
   - **推穿**：前一镜加速推进（径向模糊），后一镜从放大状态减速拉开。
   - **甩镜**：方向性运动模糊，前后速度衔接。
   - **负片闪**：反转一两帧，用于「¡Olé!」「Enamorar!!」「Especial!!」。
   - **扇形擦除**：一把扇子展开，带出下一镜。
   - **裙摆擦除**：荷叶边扫过画面。
   - **拱门／圆形匹配剪辑**：太阳 → 圆章 → 月亮 → 表盘。
   - **面板推入**：竖条依次滑入，用于对唱。
4. **镜头内的连续性**：例如前奏里，一个镜头沿着五座拱门甩过去（芳乃 → 凪 → 心），「¡Olé!」时急速拉远，看到全景。
5. **潜意识闪帧**：副歌里偶尔闪一帧下一段的画面（1/16 拍）。

## 4. 歌词排版规则

- 字逐个「爆」出：每个字唱到时，从 1.6 倍大小、白热发光的状态缩回原位，再冷却成本色；汉字大、假名小。
- 整行在屏幕上缓慢漂移，字距微微展开；退场时模糊、上浮、错开消失，或者跟着转场一起被闪白吞掉。
- 西语口号（Enamorar!! / Especial!! / Amanecer!! / ¡Olé! / Lleno de amor）：大号衬线体砸入，配负片闪或闪白。
- 歌词属于镜头：跟着镜头一起被转场带走，不会一直浮在最上层。
- 脸部避让：每个镜头登记人物脸部范围，歌词排在空白处；程序检查，冲突时换边。

## 6. 制作顺序

1. 先做试映段 0:00–1:19（前奏 → 副歌 1 → 间奏），用来确认运动感和转场方向。
2. 方向确认后，按同一套规则做完全片。
